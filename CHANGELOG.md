# Changelog

## [1.0.0] - 2025-06-21

- Initial release of Copilot Metrics lite Dashboard extension.
- Dashboard showing completions, lines, characters generated.
- Per-file and per-language statistics.
- Pagination support for large file lists.
- Status bar integration.
- Manual refresh and reset metrics controls.
- Authentication integration for personalized experience.
- Auto-refresh of dashboard every 30 seconds.
